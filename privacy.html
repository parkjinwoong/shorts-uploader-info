개인정보처리방침

작성일: 2026년 10월 24일 · 현재 개인용 데스크톱 운영 범위

운영자 박진웅의 Shorts Uploader는 YouTube API Services를 사용하는 개인용 도구입니다. 운영자가 관리하는 채널의 영상 전송과 상태 확인에 필요한 정보만 사용합니다.

접근하고 사용하는 정보

  • Google OAuth 액세스 토큰과 갱신 토큰: 승인한 YouTube 기능에 접근하고 연결을 갱신하기 위해 사용합니다.
  • 채널 ID·채널명과 영상 ID·제목·설명·공개 범위·처리 상태 등 조회 결과: 대상 채널 대조, 전송 결과 확인과 중복 전송 방지에 사용합니다.
  • 운영자가 선택한 영상 파일, 제목·설명과 필요한 게시 설정: 승인한 업로드를 실행하기 위해 사용합니다.

현재 요청하는 Google 권한은 youtube.upload와 youtube.readonly입니다. Google 계정 비밀번호는 도구에서 수집하지 않습니다.

보관과 공유

연결 토큰과 업로드 재개용 세션 정보는 운영자의 Windows 사용자 계정에 묶인 DPAPI 암호화로 PC에 저장합니다. 제작 파일, 채널·영상 식별 정보와 작업 기록은 운영자의 로컬 작업 폴더·데이터베이스에 보관합니다. 이들 전체 파일이 DPAPI로 암호화된다는 뜻은 아닙니다.

업로드와 조회에 필요한 데이터는 HTTPS를 통해 Google·YouTube에 전달됩니다. 도구는 Google에서 받은 사용자 데이터를 광고, 판매 또는 일반 AI 모델 학습에 사용하지 않습니다. 이 안내 사이트에는 해당 토큰·제작 파일·비공개 작업 기록을 올리지 않습니다.

이 정적 안내 사이트는 별도의 분석 스크립트, 광고 또는 로그인 쿠키를 추가하지 않습니다. 사이트 호스팅 제공자는 접속에 필요한 IP 주소 등 기본 접속 정보를 자신의 정책에 따라 처리할 수 있습니다.

연결 해제와 데이터 삭제

Google 계정의 서드 파티 연결 관리에서 Shorts Uploader의 접근 권한을 취소할 수 있습니다. 권한 취소와 별개로 로컬에 남은 연결 정보·작업 기록의 삭제가 필요하면 운영자에게 문의할 수 있습니다. 운영자는 사용이 끝난 인증 정보와 불필요한 API 조회 데이터를 정리하며, 법령상 보관 의무가 없는 삭제 요청은 7일 이내 처리합니다.

이 도구의 로컬 파일을 삭제하거나 계정 연결을 해제해도 YouTube에 이미 올라간 영상이 자동으로 삭제되지는 않습니다. 영상 삭제와 공개 범위 변경은 별도로 YouTube Studio 등에서 수행해야 합니다.

정책과 문의

Google 사용자 데이터의 사용과 다른 앱으로의 전송에는 Google API Services User Data Policy의 Limited Use 요건을 포함한 정책이 적용됩니다. Google 자체의 데이터 처리는 Google 개인정보처리방침을 참고하세요.

도구가 접근하는 데이터나 사용 목적이 바뀌면 이 안내를 갱신하고, 새로운 권한이 필요할 때 다시 동의를 받습니다.
