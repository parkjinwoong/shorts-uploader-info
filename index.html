Shorts Uploader는 운영자 본인이 관리하는 YouTube 채널에 승인한 영상과 제목·설명 등을 전송하고 결과를 확인하기 위한 Windows 도구입니다. 현재 일반 이용자를 모집하거나 서비스로 배포하지 않습니다.

Google 연결을 사용하는 이유

YouTube Data API를 이용해 연결한 채널이 맞는지 확인하고, 운영자가 승인한 영상의 업로드와 처리 상태 조회에 사용합니다. API 연결 자체가 영상 공개나 반복 업로드를 승인하지는 않습니다.

  • youtube.upload: 승인한 영상 전송에 사용합니다.
  • youtube.readonly: 연결 채널과 영상 정보를 확인합니다.

계정과 연결 정보

Google의 OAuth 동의 화면에서 연결하며, 이 도구가 Google 계정 비밀번호를 받지는 않습니다. 연결 토큰은 운영자의 Windows PC에 암호화해 보관합니다. 이 안내 사이트에는 로그인·영상 업로드·계정 연결 기능이 없습니다.

자세한 데이터 처리와 연결 해제 방법은 개인정보처리방침에서 확인할 수 있습니다.
